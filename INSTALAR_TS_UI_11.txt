TS-UI-11 + TS-UI-10.02 — Player Career History / English trophies

BASE OBLIGATORIA: TS-UI-10.01 sobre TS-FIX-07 y demás parches anteriores.

1. Hacer copia de seguridad de football-manager-2026 y de las partidas.
2. Cerrar el juego y detener el proceso Python.
3. Extraer TODO este ZIP directamente en la raíz de football-manager-2026,
   manteniendo la estructura frontend/, src/ y tests/.
4. Permitir reemplazar los archivos existentes.
5. Reiniciar Python y forzar recarga del navegador con Ctrl+F5.

No instala dependencias. No modifica el formato del guardado: versión 32.

Rama sugerida (crearla desde la última que contiene TS-UI-10.01):
feat/ts-ui-11-player-career-archive

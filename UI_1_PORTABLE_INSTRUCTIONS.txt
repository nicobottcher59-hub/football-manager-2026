FM PROJECT - UI-1 PORTABLE SIN INSTALAR NADA
==========================================

ESTE ZIP ES UN PARCHE, NO EL JUEGO COMPLETO.

1. Mantene la branch phase-ui-1-react-dashboard-shell.
2. Descomprimi el CONTENIDO del ZIP en la RAIZ del repositorio.
   Al lado de README.md, README_DEV.md, src/, frontend/, tools/.
3. Hace DOBLE CLIC en INICIAR_INTERFAZ_WINDOWS.bat.

REQUISITOS: Un navegador moderno (Edge, Chrome, Firefox).
NO necesitas instalar nada, ni tener Python en el PATH para ver esta UI-1.

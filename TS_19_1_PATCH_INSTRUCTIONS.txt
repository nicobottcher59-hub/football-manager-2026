TS-19.1 — Formation Expansion | Incremental patch

BASE REQUIRED
  Project with TS-18.5 reviewed and TS-18.6 integrated (latest TS-18 branch).
  The original supplied source ZIP was at TS-18.4; the TS-18.5/18.6 patches
  were included when running integration regression tests, but their code is
  deliberately NOT duplicated in this ZIP.

INSTALLATION (WINDOWS)
  1. Create GitHub Desktop branch: feat/ts-19-1-formation-expansion
  2. Extract the ZIP directly into the repository root, keeping all paths.
  3. Let files replace their existing versions where requested.
  4. Run: python -m pytest -ra tests/test_ts_19_1_formation_expansion.py
  5. Run: python -m pytest -ra
  6. Start INICIAR_INTERFAZ_WINDOWS.bat (no npm needed).
  7. Open Tactics -> Formation: 28 options must be available immediately.
     Test 4-3-3 (2 DM), 4-4-2 (2 DM), 4-2-4, 4-5-1 (2 AM + RM/LM),
     and 5-2-2-1 (2 central AM) in both tactical phases.
  8. Commit and merge only after local acceptance/regression.

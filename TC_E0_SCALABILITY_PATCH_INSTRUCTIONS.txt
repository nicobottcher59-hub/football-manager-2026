TC-E0: Synthetic World Scalability Diagnostic (docs/tools/tests only)

Base: UI-3.5.1 (with its final Matchday patch), optionally the previous
Technical Checkpoint documentation. Does NOT change src/ or gameplay.

1. Create a branch from UI-3.5.1, for example:
   tech-checkpoint-world-scalability-diagnostics
2. Extract this incremental ZIP in the repository root.
3. Run from the repository root:
   python -m pytest -q tests/test_world_scalability_diagnostic.py -ra
   python tools/stress_world_calendar.py --quick
4. Optional (slower, depends on CPU):
   python tools/stress_world_calendar.py --full --output reports/world_scalability_local.json
5. Review docs/TECHNICAL_CHECKPOINT_WORLD_SCALABILITY.md and the recorded results.

The xfail test is intentional: it documents a known non-atomic registration
issue and must NOT be misinterpreted as a successful rollback implementation.
All clubs/countries and the intercontinental knockout cup are stress proxies.
No real FIFA national teams, windows or Club World Cup were implemented.

2. En GitHub Desktop, crear esta nueva branch partiendo de UI-3.1.
3. Extraer el CONTENIDO de este ZIP sobre la carpeta RAIZ del repositorio.
4. Aceptar reemplazar los archivos cuando Windows lo solicite.
5. Ejecutar INICIAR_INTERFAZ_WINDOWS.bat desde la raiz.
6. En Chrome o Edge presionar Ctrl+Shift+R para recargar sin cache.
7. Entrar a Calendar y probar meses, Today, filtros y clic en partidos.
8. Entrar a Squad, hacer clic en POS para comprobar orden deportivo e inverso.
9. No hacer commit hasta verificar estas interacciones y comunicar el resultado.

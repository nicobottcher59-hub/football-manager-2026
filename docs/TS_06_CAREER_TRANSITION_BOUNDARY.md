# TS-06 — Career / Competition Decoupling (foundation)

Incremental architecture patch based on TS-05. Does not introduce leagues, countries, finances, custom clubs or new football rules. England's current behavior remains the default.

## Problem

`WorldCareer` previously called England-specific `finalize_season()` and `next_season_world()` directly, and archive loading assumed exactly four English leagues. This makes plugging in a different country's rules difficult even when `WorldSeasonRunner` can already run independent synthetic leagues.

## Change

- Define a versioned `CareerSeasonTransition` protocol for finalizing a season and building the next.
- Provide `EnglishCareerTransition` using the **existing** English rules unchanged. `WorldCareer` defaults to this strategy without requiring callers to change.
- Include a `transition_id` in career archives (existing schema version 1 remains supported; old archives without the field default to England).
- Fail explicitly when an archive references an unregistered transition rather than treating it as England. Country-specific loaders may pass a mapping of transition implementations to `load_json` / `from_dict`.
- Validate every season-to-season roster transition both when moving to the next season and when loading an archive. England still enforces its four-tier roster.
- Fix a real atomicity edge case: names generated by a partially failing next-season builder no longer leak into the current `club_names` dictionary.

## Tests (Python only)

```
python -m pytest -q -ra tests/test_ts_06_career_transition_boundary.py tests/test_phase6_7_full_season_integration.py
```

Includes compatibility with old archives, a synthetic one-country transition with two saved worlds, explicit registry loading, rejecting unknown transition types, and rollback of names/season history on a failed transition.

## Scope limits

- A strategy boundary is not a playable world with multiple national pyramids. Future content must implement each country's actual promotions, continental qualification and calendar rules.
- The current 2026/27 England season data / fast simulator are not modified.
- Career archives still store results-world history, not complete manager-player-tactic-save state.
